1.Version Control System (VCS) คือระบบที่ใช้จัดการและบันทึกประวัติการเปลี่ยนแปลงของไฟล์หรือซอร์สโค้ดภายในโปรเจกต์ ช่วยให้สามารถตรวจสอบ ย้อนกลับ หรือเรียกคืนเวอร์ชันก่อนหน้าได้เมื่อต้องการ รวมถึงช่วยลดความผิดพลาดระหว่างการพัฒนาโปรแกรม
ประโยชน์ของ Version Control
ติดตามประวัติการแก้ไข: สามารถตรวจสอบได้ว่าใครเป็นผู้แก้ไขไฟล์ แก้ไขเมื่อใด และมีการเปลี่ยนแปลงอะไร
รองรับการทำงานเป็นทีม: นักพัฒนาหลายคนสามารถทำงานในโปรเจกต์เดียวกันได้โดยไม่เกิดปัญหาไฟล์ทับกัน
กู้คืนเวอร์ชันเดิมได้: หากเกิดข้อผิดพลาดหลังจากแก้ไขโค้ด สามารถย้อนกลับไปยังเวอร์ชันก่อนหน้าได้อย่างรวดเร็ว
รองรับการสร้าง Branch: สามารถแยกสายการพัฒนาเพื่อทดลองฟีเจอร์ใหม่ และนำกลับมารวมกับโค้ดหลักเมื่อพร้อมใช้งาน

2.Core Objectives of Git

Git ถูกสร้างขึ้นโดย Linus Torvalds ในปี 2005 เพื่อใช้บริหารจัดการซอร์สโค้ดของ Linux Kernel โดยมีวัตถุประสงค์สำคัญดังนี้

ประสิทธิภาพสูง: ทำงานได้รวดเร็วทั้งการ Commit, Branch และ Merge
Distributed Version Control: ผู้พัฒนาแต่ละคนมีสำเนาของ Repository ทั้งหมดบนเครื่องของตนเอง จึงสามารถทำงานแบบออฟไลน์ได้
Data Integrity: ใช้ระบบ Hash (เช่น SHA-1 และ SHA-256) เพื่อรักษาความถูกต้องของข้อมูลและตรวจจับการเปลี่ยนแปลงที่ไม่พึงประสงค์
รองรับการพัฒนาแบบหลายสาย (Branching): ช่วยให้สามารถพัฒนาฟีเจอร์หลายส่วนพร้อมกันได้อย่างมีประสิทธิภาพ
Atomic Commit: การบันทึกข้อมูลจะสำเร็จทั้งหมดหรือไม่สำเร็จเลย เพื่อป้องกันข้อมูลไม่สมบูรณ์

3.Git's Internal Object Model

Git จัดเก็บข้อมูลในรูปแบบ Directed Acyclic Graph (DAG) โดยใช้ Object หลัก 4 ประเภท ดังนี้

Blob: ใช้เก็บข้อมูลภายในไฟล์ โดยไม่เก็บชื่อไฟล์หรือข้อมูลอื่น ๆ
Tree: ใช้แทนโฟลเดอร์ ทำหน้าที่เชื่อมโยงไปยัง Blob หรือ Tree อื่น พร้อมเก็บชื่อไฟล์และสิทธิ์การใช้งาน
Commit: บันทึกสถานะของโปรเจกต์ในช่วงเวลาหนึ่ง พร้อมข้อมูลผู้สร้าง วันที่ และข้อความอธิบายการเปลี่ยนแปลง รวมถึงเชื่อมโยงกับ Commit ก่อนหน้า
Annotated Tag: ใช้กำหนดจุดสำคัญของโปรเจกต์ เช่น เวอร์ชันที่เผยแพร่ พร้อมข้อความหรือข้อมูลเพิ่มเติม

4.ObjectiveGit Library

ObjectiveGit เป็นไลบรารีแบบ Open-source ที่พัฒนาขึ้นบนพื้นฐานของ libgit2 เพื่อให้นักพัฒนาที่ใช้ Objective-C หรือ Swift สามารถเรียกใช้งานความสามารถของ Git ได้โดยตรงภายในแอปพลิเคชัน โดยไม่จำเป็นต้องสั่งงานผ่าน Terminal
การใช้งานหลักคือการพัฒนาโปรแกรม Git Client บนระบบ macOS และ iOS หรือแอปที่ต้องจัดการ Git Repository ภายในตัว อย่างไรก็ตาม ปัจจุบันได้รับความนิยมน้อยลง เนื่องจากมีทางเลือกใหม่ เช่น SwiftGit2 ที่รองรับภาษา Swift ได้ดีกว่า
